# 测验与作业收集系统

一个简单高效的在线测验和作业收集平台，支持多种题型，实时统计分析。

## 功能特性

### 📋 表单管理
- **创建表单**: 快速创建测验、作业或调查表单
- **多种题型**: 支持文本题、数字题、单选题、多选题
- **表单配置**: 自定义表单标题、描述和类型
- **问题管理**: 动态添加、删除和编辑问题

### 🔗 分享收集
- **一键分享**: 为每个表单生成唯一的分享链接
- **便捷访问**: 用户通过链接直接访问和填写表单
- **实时验证**: 表单提交前的完整性验证
- **用户友好**: 清晰的界面指导和操作提示

### 📊 数据统计
- **提交统计**: 实时查看提交数量和时间
- **可视化图表**: 表单类型分布和提交趋势图表
- **详细分析**: 查看每个提交的具体答案内容
- **数据导出**: 支持 CSV 格式导出所有提交数据

### 💾 数据存储
- **本地存储**: 使用浏览器 localStorage 存储数据
- **自动保存**: 表单创建和提交自动保存
- **数据持久**: 关闭浏览器后数据不丢失

## 快速开始

### 1. 直接使用
打开 `index.html` 文件即可开始使用，无需安装任何依赖。

### 2. 创建第一个表单
1. 点击 "创建表单" 按钮
2. 填写表单标题和描述
3. 选择表单类型（测验/作业/调查）
4. 添加问题和选项
5. 点击 "创建表单" 完成

### 3. 分享表单
1. 在 "管理表单" 页面找到创建的表单
2. 复制分享链接
3. 将链接发送给需要填写的用户

### 4. 查看结果
1. 在 "管理表单" 页面点击 "查看提交"
2. 查看每个提交的详细答案
3. 使用 "导出数据" 功能下载 CSV 文件
4. 在 "统计分析" 页面查看整体数据分析

## 系统架构

### 前端技术
- **AngularJS 1.8**: 数据绑定和页面控制
- **Bootstrap 5**: 响应式 UI 框架
- **Chart.js**: 图表可视化
- **Font Awesome**: 图标库

### 数据存储
- **localStorage**: 浏览器本地存储
- **JSON格式**: 结构化数据存储

### 文件结构
```
├── index.html          # 主页面 - 表单管理
├── submit.html         # 提交页面 - 用户填写表单
├── css/
│   └── style.css       # 自定义样式
├── js/
│   ├── app.js          # 主应用逻辑
│   └── submit.js       # 提交页面逻辑
└── src/
    └── angular-chartjs-directive.js  # 图表指令
```
